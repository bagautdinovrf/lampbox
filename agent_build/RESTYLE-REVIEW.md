# Проверка рестайла MediaBoxManager

Реализован интерфейс Qt Widgets по композиции «Прилив»: независимые оформления **Оригинал / Рельеф** и семь тем. По умолчанию — **Рельеф + Деним**. Нет QSS, WebEngine или скрытого старого главного окна. Переключение использует существующий Settings и не пересоздаёт модели/редакторы.

Главное окно, расписание, медиатека, сведения о файле/станции, редакторы каналов и рекламы, настройки, отчёты, About, подтверждения и trial оформлены общим QProxyStyle/QPalette. Добавление файлов открывает QFileDialog и использует действующий импорт. Поиск/сортировка работают через proxy; команды преобразуют индекс обратно в исходную модель. Отмена редактора не сохраняет черновик. Вспомогательный расчёт расписания не управляет эфиром и не изображает телеметрию плеера.

**Плеер не менялся:** `MediaBoxPlayer/`, `src/mediacontroller.cpp/.h` и исторические команды/ключи остались без изменений. Установка и публикация дистрибутива не выполнялись.

## Сборка и проверки

Сборка выполнена в предоставленном Linux-окружении: Qt 6.12, GCC 14, CMake/Ninja, существующий TagLib. Версии проекта и требования к toolchain не понижались.

- Приложение: `agent_build/build/bin/MediaBoxManager` — Linux, не Windows EXE.
- Изолированный UI preview: `agent_build/build/bin/MediaBoxManager_restyleTests`.
- CTest: 10 наборов проходят, включая существующие проверки и новые UI/расписание/редакторы/вторичные страницы.
- AddressSanitizer: UI-проверки проходят после исправления порядка уничтожения views/models/managers. Проверка утечек отключена; это не заявление об отсутствии всех утечек Qt/приложения.
- Проверены независимое сохранение двух ID, неизвестные значения и defaults, состояние формы/поиска/выделения при смене 14 сочетаний, proxy/source mapping, сортировка длительности, удаление выбранного файла после сортировки, локальный drag-and-drop, импорт в выбранный второй канал и отмена настоящего подтверждения удаления, checkbox/Space/контекстное меню, cancel/валидация и отказ записи редакторов, настоящие и ошибочные отчёты.
- Календарный адаптер проверен на границах года/месяца, високосном дне, Sunday=0, пересечениях, конце полуоткрытого интервала и переходах DST. Равные/ночные интервалы с неподтверждённой семантикой объясняются отдельно. Частота рекламы не превращается в выдуманные точные минуты.

Журналы: `restyle-build.log`, `restyle-test.log`; результаты каждого набора — `build/tests/*-results.txt`. Windows/MSVC-сборка и работа настоящего проигрывания здесь не запускались.

## Границы подтверждённого результата

Точное воспроизведение всей картинки **1:1 не подтверждено**. В Linux нет Segoe UI; изображения используют DejaVu Sans с проверенными русскими глифами. Отличаются ширина/плотность шрифта и растеризация. Windows запуск загружает локальные `segoeui.ttf`, `seguisb.ttf`, `segoeuib.ttf`; системные шрифты не копируются в репозиторий. Для локального законно предоставленного набора доступен `MEDIABOX_FONT_DIRECTORY`.

Двойные тени и размытие подложки воспроизведены средствами QPainter; алгоритм не идентичен браузерному blur. Нативные scrollbars и системная рамка отличаются. В фикстуре имена каналов с подчёркиванием соблюдают существующий формат без пробелов. Статусы, контекст станции и подписи содержат реальные сведения; неизвестная телеметрия показана честно. Настройка неподдерживаемой демонстрационной прозрачности заменена сведениями о действующем оформлении. На небольшой логической площади шапка/навигация/служебные команды переходят к значкам с tooltip, рабочая область прокручивается.

Offscreen-масштабирование **не заменяет** проверку физического Windows-экрана 1440×900 с панелью задач, масштабом 125/150/200% и Segoe UI. Новая тёмная тема не выдаётся за исходный утверждённый браузерный эталон. Overlay/diff не маскируют панели и не объявляют общий процент сходства критерием приёмки.

## Изоляция и безопасный preview

В исходном `ChannelManager::collectChannels()` сохранён известный дефект `trial() || true`, удаляющий каналы после первого вместе с каталогами. Задание прямо исключает его неоговорённое исправление из рестайла. **Реальная медиатека не открывалась.** До использования обычного executable на существующей станции этот дефект требует отдельного исправления.

Preview-тест включает `QStandardPaths::setTestModeEnabled`, выделяет QTemporaryDir, задаёт отдельные настройки/станцию/cron-каталог до создания singleton и не создаёт MediaController. При неверном пути preview останавливается, не переходит к реестру/fallback. Все данные удаляются вместе с временной папкой.

На машине с рабочим графическим Qt backend можно открыть интерактивную временную станцию:

```sh
agent_build/build/bin/MediaBoxManager_restyleTests --preview
```

Повторить текущий безопасный offscreen-захват из корня репозитория:

```sh
QT_QPA_FONTDIR=/usr/share/fonts/truetype/dejavu \
QT_QPA_PLATFORM=offscreen:configfile=agent_build/restyle-screen-reference.json \
agent_build/build/bin/MediaBoxManager_restyleTests \
  --capture agent_build/restyle-review
python agent_build/compare-restyle.py agent_build/restyle-review
```

Обычная Windows-сборка остаётся прежней:

```powershell
powershell -ExecutionPolicy Bypass -File .\agent_build\build.ps1
```

После неё безопасный интерактивный запуск: `agent_build\build\bin\MediaBoxManager_restyleTests.exe --preview`. Сам MediaBoxManager.exe не является изолированным preview.
