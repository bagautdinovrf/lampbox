# Инструкции для работы

- Отвечай пользователю по-русски.
- При сборке разрешено без дополнительного подтверждения останавливать все процессы, которые мешают сборке, тестам или обновлению файлов приложения. Перед остановкой определи мешающие процессы по пути исполняемого файла, блокировке файлов или занятому порту.
- Перед созданием или изменением интерфейса прочитай [памятку по дизайну](design-concepts/DESIGN.md). Основная база — официальные Apple Human Interface Guidelines по ссылкам в памятке; учитывай решения проекта и актуальный запрос пользователя.
- Дополняй существующую памятку только решениями проекта. Подробные рекомендации Apple сохраняй ссылками на первоисточники.
